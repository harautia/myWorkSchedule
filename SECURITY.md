# Security policy

## Reporting a vulnerability

**Please don't report security problems in public issues.**

Report them privately through GitHub instead:
[open a private vulnerability report](https://github.com/harautia/myWorkSchedule/security/advisories/new).
Only the maintainers can see it.

Please include:

- what the problem is and what an attacker could do with it
- steps to reproduce it, or a proof of concept
- the version (or commit) you tested, and whether it was self-hosted or the hosted service

You'll get a reply within 7 days. Once a fix is released, the report is published as a
GitHub security advisory, and you're credited unless you'd rather not be.

## Supported versions

Security fixes go into the latest release. Self-hosters should keep up to date; see
[Upgrading](https://harautia.github.io/myWorkSchedule/self-hosting/upgrading/).

## Scope

Especially welcome are reports about one bar being able to see or change another
bar's data (tenant isolation), authentication and sessions, and anything that exposes
personal data.
