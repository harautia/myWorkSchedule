## What it does

<CardGrid>
  <Card title="Plan the week" icon="pencil">
    Drag shifts to move them, drag the bottom edge to change the end time, or add the
    same shift on several days at once. Shifts past midnight belong to the evening they
    start, the way bar days work.
  </Card>
  <Card title="Publish when it's ready" icon="approve-check">
    Each week is either being planned or locked. Employees only see locked weeks, and
    if you unlock a week to fix something, they keep seeing the last published version
    until you lock it again.
  </Card>
  <Card title="On every phone" icon="phone">
    Employees open "My shifts" to see when they work. It installs on the home screen
    like an app and shows the last loaded schedule even offline.
  </Card>
  <Card title="Several bars, clear roles" icon="building">
    One installation can serve several bars, each fully separated. Admins create bars,
    managers plan their own bar, and employees see the schedule.
  </Card>
</CardGrid>

## Run it your way

<CardGrid>
  <Card title="Host it yourself" icon="setting">
    Everything is open source under the AGPL-3.0 licence. One Docker Compose file runs the
    app and its database; see the [installation guide](self-hosting/install/).
  </Card>
  <Card title="Hosted service" icon="rocket">
    A hosted service, run by the author, is planned for bars that would rather not
    maintain a server. It will have exactly the same features.
  </Card>
</CardGrid>
